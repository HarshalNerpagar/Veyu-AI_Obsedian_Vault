## Vault Structure

Every folder exists for a reason. Nothing here is decorative.

```
Veyu-AI/
│
├── Team/                → Who we are, what we own, where we focus
├── Standups/            → Daily async check-ins (the accountability engine)
├── Weekly/              → Weekly sync notes + AI-generated reviews
├── OKRs/                → Quarterly goals — what winning looks like
│
├── Projects/            → All active work (client + internal)
├── Clients/             → CRM — every client relationship, documented
├── Pipeline/            → Sales leads — tracking who we're talking to
│
├── Knowledge/           → Shared research, learnings, domain expertise
├── SOPs/                → How we deliver — repeatable, improvable processes
├── Decisions/           → The decision log (prevents "who decided this?")
│
├── Finance/             → Revenue, expenses, invoices — every rupee tracked
├── Legal/               → Compliance calendar, contracts, company docs
│
├── Ideas/               → Product ideas born from client work
├── Retrospectives/      → Monthly honest reviews — what worked, what didn't
│
├── Templates/           → Standardized formats for everything above
└── Archive/             → Completed work (nothing gets deleted, just archived)
```

### What Each Piece Does

| Folder | Why It Matters |
|---|---|
| **Standups/** | The #1 accountability mechanism. If you're not logging, you're not working. AI reviews these daily. |
| **Decisions/** | Three co-founders = three opinions. Logging decisions with *why* prevents every future argument about "I never agreed to that." |
| **SOPs/** | We do the same work repeatedly for different clients. SOPs mean we do it faster and better every time. This is how agencies scale. |
| **Pipeline/** | Revenue doesn't appear magically. Tracking leads → conversations → proposals → wins is how we build predictable income. |
| **Finance/** | Cash flow kills more startups than bad ideas. We track every rupee in, every rupee out. No surprises. |
| **Legal/** | We're a Pvt Ltd. Missing an ROC filing can cost ₹1L+ in penalties. The compliance calendar keeps us legal. |
| **OKRs/** | Without measurable goals, we're just busy. OKRs force us to define what "winning" looks like every quarter. |
| **Retrospectives/** | We're going to make mistakes. Retros make sure we never make the same one twice. |

## AI Agents

We can't afford a COO, CFO, lawyer, or PM. So we built them.

Five AI agents run inside this vault through [Claude Code](https://claude.ai). They read our notes, analyze our patterns, and do jobs that would otherwise fall through the cracks.

| Agent | Role | What It Does |
|---|---|---|
| 🎖️ **Chief of Staff** | Accountability | Reviews standups, flags missed days, tracks velocity, runs weekly reviews. The one who asks "why didn't you ship?" |
| ⚖️ **Legal Advisor** | Compliance | Tracks Pvt Ltd filing deadlines, reviews contracts for red flags, reminds us about GST/TDS/ROC. Keeps us out of trouble. |
| 💰 **CFO** | Finance | Tracks revenue per client, monitors expenses, calculates runway, flags overdue invoices. The money person. |
| 🧭 **Strategist** | Direction | Challenges our assumptions, analyzes market opportunities, connects dots between client work and product ideas. The one who asks "should we even be doing this?" |
| 📋 **PM** | Delivery | Tracks project timelines, assigns tasks by skillset, flags blockers, runs kickoffs and debriefs. Keeps client work on time. |

**These aren't chatbots.** They have full context of our vault — every standup, every decision, every client note. They actively monitor and flag issues before we notice them.

## How We Work

### Daily (2 min each)
Open today's standup. Log three things:
- ✅ What I did yesterday
- 🎯 What I'm doing today
- 🚧 What's blocking me

### Weekly (30 min sync)
AI generates a review from the week's standups. We discuss, make decisions, plan next week.

### Monthly (1 hour retro)
What went well. What didn't. What we're changing. Brutally honest.

### Quarterly (half day)
Set OKRs. Review last quarter. Adjust strategy.

**The rule:** If it's not in the vault, it didn't happen.

## Getting Started

```bash
# 1. Clone
git clone https://github.com/HarshalNerpagar/Veyu-AI_Obsedian_Vault.git

# 2. Open as vault in Obsidian
# File → Open Vault → select the cloned folder

# 3. Install community plugins
# - Obsidian Git (auto-sync)
# - Templater (templates)
# - Dataview (optional, for queries)

# 4. Start with your standup
# Open Standups/ → create today's file using Templates/Standup
```

### Git Sync Rules
- **Auto-pull** on Obsidian open
- **Auto-push** on close (or every 10 min)
- **Only edit files you own** to avoid merge conflicts
- Standups: each person fills their own section
