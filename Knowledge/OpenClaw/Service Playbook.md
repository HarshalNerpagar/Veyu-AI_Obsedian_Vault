# Service Playbook

## Summary

The operational blueprint for the [[OpenClaw Agency]]. Covers pricing architecture, platform strategies (Fiverr + Upwork), website structure, differentiation, lead magnets, messaging, and revenue projections. This is the "how" document — everything needed to launch and execute.

## Details

### 4-Tier Pricing Architecture

#### Tier 1: Quick Fix — $149
- **Scope:** Single issue resolution
- **Includes:** 1 specific problem fixed (installation error, config issue, skill bug)
- **Delivery:** 24-48 hours
- **Target:** Frustrated users who just need one thing to work
- **Margin:** ~85% (1-2 hours of work)

#### Tier 2: Essential Setup — $497
- **Scope:** Full installation + configuration + security basics
- **Includes:** Clean install, basic security hardening, 3 pre-built skills, 1 hour training call
- **Delivery:** 3-5 business days
- **Target:** Solo entrepreneurs and small businesses getting started
- **Margin:** ~75% (4-6 hours of work)

#### Tier 3: Professional — $997
- **Scope:** Setup + custom skills + workflow automation + training
- **Includes:** Everything in Essential + 3 custom skills, Lobster workflow setup, API integration, 2 hours training
- **Delivery:** 7-10 business days
- **Target:** Businesses wanting real automation, not just setup
- **Margin:** ~70% (8-12 hours of work)

#### Tier 4: Business Transformation — $2,497
- **Scope:** Multi-agent deployment + integrations + security audit + support
- **Includes:** Everything in Professional + multi-agent architecture, full security audit, CRM/database integrations, 30 days email support
- **Delivery:** 2-3 weeks
- **Target:** Mid-market companies deploying AI at scale
- **Margin:** ~65% (20-30 hours of work)

#### Recurring: Managed Plan — $199/mo
- **Scope:** Ongoing monitoring, updates, optimization, priority support
- **Includes:** Monthly health check, security updates, skill updates, 2 hours/mo support, priority response
- **Target:** Any client who wants "set and forget" peace of mind
- **Margin:** ~80% (2-3 hours/mo)

### Fiverr Gig Blueprint

**Title:** "I Will Set Up, Secure & Optimize Your OpenClaw AI Agent"

**Description key points:**
- Lead with security: "135K+ OpenClaw instances are exposed online. Is yours one of them?"
- Highlight expertise: "50+ successful deployments"
- Social proof: Include screenshots, before/after metrics
- Urgency: "Most setups have critical security gaps you don't know about"

**Three Fiverr Tiers:**

| Tier | Name | Price | Includes |
|------|------|-------|----------|
| Basic | Quick Fix | $149 | 1 issue resolved, 24-48hr delivery |
| Standard | Essential Setup | $497 | Full install + security + 3 skills + training |
| Premium | Professional | $997 | Custom skills + workflows + API integration + 2hr training |

**Gig extras:**
- Security audit add-on: +$199
- Additional custom skill: +$99 each
- Rush delivery (same day): +$99
- Managed plan upsell: $199/mo

### Upwork Strategy

**Profile headline:** "OpenClaw AI Agent Expert | Setup, Security & Automation | 50+ Deployments"

**Profile key sections:**
- Lead with security credentials and specific vulnerability knowledge
- Showcase 3 detailed case studies (even if reconstructed from personal projects initially)
- List specific technical skills: Docker, API integration, Lobster workflows, skill development
- Include "enterprise ready" keywords: RBAC, SSO, compliance, governance

**Project listing approach:**
- Bid on every OpenClaw job within 1 hour of posting
- Custom proposal template referencing their specific needs
- Include a free "security quick scan" offer in every proposal
- Price 20-30% below Zachary F. ($75-100/hr) but above Indian generalists ($15-35/hr)
- Target rate: $40-60/hr

### 5 Differentiation Points to Own

1. **"Security-first OpenClaw agency"** — nobody else leads with security
2. **"Full-stack, not just setup"** — setup + security + optimization + managed
3. **"Managed plans for peace of mind"** — recurring revenue nobody else offers
4. **"Enterprise-ready deployments"** — RBAC, SSO, audit logging, compliance
5. **"Transparent pricing, no surprises"** — published tiers vs "contact for quote"

### Lead Magnets That Convert

1. **"OpenClaw Security Checklist"** — Free PDF, 15-point security audit you can do yourself (captures emails)
2. **"OpenClaw Cost Calculator"** — Interactive tool showing token spend estimates (captures emails)
3. **"Top 10 OpenClaw Mistakes"** — Blog post / PDF with common setup errors (SEO + email capture)
4. **"Free Security Quick Scan"** — Offer in Upwork proposals: "I'll check your instance for free" (foot in the door)
5. **"OpenClaw ROI Template"** — Spreadsheet to calculate automation ROI (captures emails, qualifies leads)

## My Take

The playbook is designed for speed-to-revenue. Fiverr and Upwork provide immediate access to buyers without needing SEO traction or a brand. The managed plan is the long-term play — 10 clients at $199/mo = $2K/mo recurring that compounds. The content flywheel takes 2-3 months to kick in but creates a moat that freelancers can't replicate.
