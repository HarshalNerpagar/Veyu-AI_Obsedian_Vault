# Sales Pipeline

Leads and prospects — people/businesses we're talking to who aren't clients yet.

## Stages
| Stage | Meaning |
|-------|---------|
| `#pipeline/cold` | Identified, not contacted |
| `#pipeline/contacted` | Reached out, awaiting response |
| `#pipeline/talking` | In conversation |
| `#pipeline/proposal` | Sent proposal/quote |
| `#pipeline/won` | Converted → move to Clients/ |
| `#pipeline/lost` | Didn't convert |
